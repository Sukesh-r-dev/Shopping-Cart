# ShopStream — Premium Modern Store

ShopStream is a lightweight, responsive, single-page modern e-commerce storefront built with HTML5, JavaScript (ES6+), and styled using Tailwind CSS via CDN.

## Features

- **Product Catalog & Filtering**: Browse products with live category filtering (`Electronics`, `Accessories`, `Apparel`) and real-time search.
- **Interactive Shopping Cart**:
  - Slide-over cart drawer.
  - Dynamic quantity adjustment and item removal.
  - Real-time subtotal, 8% tax calculation, and shipping fee logic.
  - Interactive free shipping progress tracker (unlocked at $100+).
  - Promo code support (Use coupon code `SAVE10` for 10% off).
- **Wishlist**: Toggle products to and from a personal wishlist with a live item counter badge.
- **Authentication Modals**: Built-in tabbed Sign In and Create Account modal dialogs.
- **Responsive Design**: Fully mobile-friendly layout with sticky navigation and mobile-optimized search.

## Tech Stack

- **HTML5**
- **JavaScript (Vanilla ES6)**
- **Tailwind CSS** (via CDN)
