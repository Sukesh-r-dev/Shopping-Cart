**ShopStream** is a sleek, highly responsive single-page e-commerce storefront built with standard Web technologies. It delivers a fast, seamless shopping flow using client-side JavaScript (ES6+) and Tailwind CSS—requiring zero external frameworks or backend dependencies to run.

---

## ✨ Core Features

* **📦 Smart Product Catalog:**
  * Real-time text search across item names and descriptions.
  * Instant category filtering (`Electronics`, `Accessories`, `Apparel`).

* **🛒 Interactive Slide-Over Cart:**
  * Dynamic item quantity adjustments and inline removal.
  * Live calculations for subtotal, sales tax (**8%**), and dynamic shipping rates.
  * **Free Shipping Tracker:** Visual progress meter unlocking free shipping on orders over **$100**.
  * **Promo Code Engine:** Instant coupon validation (Apply `SAVE10` for 10% off).

* **❤️ Live Wishlist:**
  * One-click save toggle with real-time updates to the navbar badge.

* **🔐 Authentication System:**
  * Tabbed modal overlay for *Sign In* and *Account Creation*.

* **📱 Mobile-First Interface:**
  * Fully responsive design featuring sticky navigation and touch-optimized controls.

---

## 🛠️ Tech Stack

* **Structure:** HTML5
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (CDN)
* **Logic:** Vanilla JavaScript (ES6+)
* **Icons:** SVG / Heroicons
